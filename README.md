# Basic Chatbot

This is a simple rule-based chatbot developed using Python.

## Features

- Responds to predefined user messages
- Uses if-elif-else conditions
- Uses a function for chatbot responses
- Uses a while loop
- Takes input from the user
- Exits when the user types "bye"

## Technologies Used

- Python 3

## How to Run

Open the terminal and run:

python3 main.py

## Example

You: hello
Bot: Hi!

You: how are you
Bot: I'm fine, thanks!

You: bye
Bot: Goodbye!
