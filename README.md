# Basic Chatbot

This is a simple rule-based chatbot developed using Python. It responds to common user messages based on predefined conditions.

## Features

- Responds to basic user messages
- Uses if-elif-else conditions
- Uses a function for chatbot responses
- Uses a while loop for continuous conversation
- Takes input from the user
- Exits when the user types "bye"

## Technologies Used

- Python 3

## How to Run

Open the terminal and run:

```bash
python3 main.py

Example

You: hello
Bot: Hi!

You: how are you
Bot: I'm fine, thanks!

You: bye
Bot: Goodbye!

Requirements

No external Python packages are required. This project uses only the Python Standard Library.
